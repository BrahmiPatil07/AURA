# ✦ AURA

### AI Utility & Research Assistant

AURA is an AI-powered personal assistant built using Python and Streamlit. It can understand user requests, decide which tool is appropriate, execute the tool, and provide the final response.

## 🚀 Features

- 🧠 AI agent with tool-calling capabilities
- 🧮 Mathematical calculations
- 🌐 Web research and latest information
- 🕐 Current date and time
- 📄 TXT, PDF, and DOCX document reading
- 📎 Document attachment directly through the chatbox
- 💾 Persistent conversation memory
- ⚙️ Agent activity workflow
- 🎭 Context-aware interface stickers
- 🎨 Clean Streamlit-based user interface
